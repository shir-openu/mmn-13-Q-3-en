Solving a System of Differential Equations

3×3 Non-Homogeneous System with a Double Eigenvalue

The Problem

Find the general solution of the system:
dx/dt = 4x − y − z + e3t
dy/dt = x + 5y + 2z + e3t
dz/dt = y + 5z
A =  4   −1   −1   1    5     2   0    1     5  b = e3t 1 1 0

Solution Method

Non-homogeneous system x' = Ax + b. We find the homogeneous solution (3 linearly independent solutions) and the particular solution. λ=4 is a double eigenvalue and requires a generalized eigenvector.

Step 1 Solution - Finding Eigenvalues

The characteristic polynomial |λI − A|:
|λI − A| = det[λ−4, 1, 1; −1, λ−5, −2; 0, −1, λ−5]
Expanding the determinant:
= (λ−4)[(λ−5)(λ−5) − (−2)(−1)] − 1[(−1)(λ−5) − (−2)(0)] + 1[(−1)(−1) − (λ−5)(0)]
= (λ−4)(λ²−10λ+25−2) − 1(−λ+5) + 1(1)
= (λ−4)(λ²−10λ+23) + λ − 5 + 1
= (λ−4)(λ²−10λ+23) + λ − 4
= (λ−4)(λ²−10λ+24)
= (λ−4)(λ−4)(λ−6)

The Eigenvalues

λ₁ = 6 (simple), λ₂ = 4 (double, algebraic multiplicity 2)

Step 2 Solution - Eigenvector for λ=6

The matrix (6I − A):
6I − A = [2, 1, 1; −1, 1, −2; 0, −1, 1]
Row reduction:
R₂ → R₂ + ½R₁: [2, 1, 1; 0, 3/2, −3/2; 0, −1, 1]
R₃ → R₃ + ⅔R₂: [2, 1, 1; 0, 3/2, −3/2; 0, 0, 0]
Solution:
v₃ = t (free), v₂ = t, v₁ = −t
Choosing t = 1: v₁ = [−1, 1, 1]T

The Eigenvector

v₁ = [−1, 1, 1]T

Step 3 Solution - Eigenvector for λ=4

The matrix (4I − A):
4I − A = [0, 1, 1; −1, −1, −2; 0, −1, −1]
Row reduction:
R₃ → R₃ + R₁: [0, 1, 1; −1, −1, −2; 0, 0, 0]
R₂ → R₂ + R₁ (swap): [−1, −1, −2; 0, 1, 1; 0, 0, 0]
Solution:
v₃ = t (free), v₂ = −t, v₁ = t
Choosing t = −1: v₂ = [1, 1, −1]T
Important note:
The geometric multiplicity is 1 (only one eigenvector), while the algebraic multiplicity is 2.
Therefore, we will need a generalized eigenvector in the next step.

The Eigenvector

v₂ = [1, 1, −1]T

Step 4 Solution - Generalized Eigenvector and Third Solution (Full Detail)

Part A: Why do we need a generalized eigenvector?
λ=4 is a double eigenvalue (algebraic multiplicity 2) but has only one eigenvector (geometric multiplicity 1).
Therefore, the third solution is not of the standard form eλtv, and requires a generalized eigenvector.
Part B: Form of the third solution
x₃(t) = te4tv₂ + e4tw
Part C: Finding w - Solving (A − 4I)w = v₂
[0, −1, −1; 1, 1, 2; 0, 1, 1] · [w₁; w₂; w₃] = [1; 1; −1]
Part D: Solving the system
Equation 1: −w₂ − w₃ = 1
Equation 3: w₂ + w₃ = −1 (identical to Equation 1)
Equation 2: w₁ + w₂ + 2w₃ = 1

From Equation 1: w₂ = −1 − w₃
Substituting into Equation 2: w₁ + (−1 − w₃) + 2w₃ = 1
w₁ + w₃ = 2 → w₃ = 2 − w₁
w₂ = −1 − (2 − w₁) = w₁ − 3

Choosing w₁ = 0: w₂ = −3, w₃ = 2
Part E: The third solution
x₃(t) = te4t[1;1;−1] + e4t[0;−3;2]
= e4t[t; t−3; −t+2]
= e4t[t; t−3; 2−t]

The Generalized Eigenvector and Third Solution

w = [0, −3, 2]T
x₃(t) = e4t[t, t−3, 2−t]T

Step 5 Solution - Particular Solution

Substituting xp = e3t[a₁, a₂, a₃]T into the system:
3e3t[a₁;a₂;a₃] = A·e3t[a₁;a₂;a₃] + e3t[1;1;0]
Canceling e3t and simplifying:
(3I − A)[a₁;a₂;a₃] = [1;1;0]
The matrix (3I − A):
[−1, 1, 1; −1, −2, −2; 0, −1, −2]
Solving the system:
From Equation 3: a₂ + 2a₃ = 0 → a₂ = −2a₃
From Equation 2: −a₁ − 2a₂ − 2a₃ = 1 → −a₁ + 4a₃ − 2a₃ = 1 → −a₁ + 2a₃ = 1
From Equation 1: −a₁ + a₂ + a₃ = 1 → −a₁ − 2a₃ + a₃ = 1 → −a₁ − a₃ = 1

From Equations 2 and 1: 2a₃ − (−a₃) = 0 → 3a₃ = 0 → a₃ = 0
a₂ = 0, a₁ = −1

The Particular Solution

xp(t) = e3t[−1, 0, 0]T

The General Solution

x(t) = −C₁e6t + C₂e4t + C₃te4t − e3t
y(t) = C₁e6t + C₂e4t + C₃(t−3)e4t
z(t) = C₁e6t − C₂e4t + C₃(2−t)e4t
